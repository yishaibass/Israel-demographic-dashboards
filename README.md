# Israel demographic dashboards

Interactive Hebrew dashboards and the reproducible source code used to build them.

- **balance-sheet/** — Israeli household balance sheet (CBS longitudinal survey 2012–2023)
- **voting-simulator/** — demographic voting-propensity explorer
- **fiscal-position/** — Fiscal net position of the three sectors, 2018→2023

The voting-model methodology, source code, input contract and reproduction commands are documented in [`modeling/README.md`](modeling/README.md). Raw Census microdata and ballot-level inputs are not distributed; their official provenance and expected local filenames are documented in [`data/raw/README.md`](data/raw/README.md).

Home page: `index.html`.
